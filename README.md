============================ INSTRUCCIONES DE EJECUCIÓN ============================
1. Necesario tener instalado expo y node_modules para poder correr la aplicación
   (si no lo tiene, abrir consola en mismo directorio donde esta App.tsx y
   correr 'npm install').
2. En una consola en el mismo directorio donde esta App.tsx correr 'npx expo start'.


URL API: 'http://localhost:3000'
